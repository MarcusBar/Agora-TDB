# Ágora — Turma do Bem

Projeto de site desenvolvido como trabalho acadêmico na **FIAP**, em parceria com a **Turma do Bem**.

## Sobre o projeto

O **Ágora** é um site institucional criado para apoiar e divulgar o trabalho da Turma do Bem, organização que oferece tratamento odontológico gratuito a jovens em situação de vulnerabilidade. O projeto foi desenvolvido em grupo, aplicando boas práticas de front-end: HTML semântico, CSS organizado por página, variáveis de estilo reutilizáveis e layout responsivo. Ainda será incrementado diversas outras funcionalidades no site, como os Dashboard funcional e controle de voluntários e pessoas em situações de vunerabilidade.

## Páginas do site

- **Início (`index.html`)**: página principal com a apresentação do projeto.
- **Sobre**: explica como o projeto funciona.
- **Integrantes**: fotos e apresentação da equipe.
- **FAQ**: perguntas frequentes, com menção às APIs e ao dashboard.
- **Contatos**: formulário e canais de contato.
- **Dashboard**: Página que mostra como será a visualização do dashboard

## Estrutura do projeto

```
Agora-TDB/
├── index.html        # Página inicial
├── css/              # Estilos (regras gerais + um CSS por página)
├── images/           # Imagens e fotos usadas no site
├── js/               # Scripts JavaScript
└── pages/            # Demais páginas do site (Sobre, Integrantes, FAQ, Contatos)
```

## Tecnologias

- HTML5 (semântico)
- CSS3 (variáveis, um arquivo por página, responsividade)
- JavaScript

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/MarcusBar/Agora-TDB.git
   ```
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.
